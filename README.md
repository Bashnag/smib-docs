# Документация СМИБ

## Назначение
Репозиторий содержит исходные тексты документированной информации системы
менеджмента информационной безопасности (СМИБ) в соответствии с п. 7.5
ISO/IEC 27001:2022. Исходные тексты ведутся в формате Markdown.

## Структура
- 01-politika/ — политика ИБ верхнего уровня
- 02-chastnye-politiki/ — частные политики
- 03-procedury/ — процедуры и регламенты
- 04-instrukcii/ — инструкции, шаблоны, чек-листы
- 05-zapisi/ — шаблоны записей

## Порядок внесения изменений
1. Прямая запись в ветку main запрещена.
2. Изменение вносится в отдельной ветке с осмысленным именем.
3. Коммит содержит описание изменения и причину.
4. Изменение передаётся через запрос на слияние (pull request).
5. Обязателен рецензент, не являющийся автором изменения.
6. После слияния утверждённая редакция помечается тегом vX.Y.
7. Изменения фиксируются в листе регистрации изменений документа.
